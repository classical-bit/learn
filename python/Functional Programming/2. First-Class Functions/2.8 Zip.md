# Zip
The zip function takes two iterables (often lists), and returns a _new_ iterable where eeach element is a tuple containing one element from each of the original iterables.

```python
a: list[int] = [1, 2, 3]
b: list[int] = [4, 5, 6]

c: list[tuple[int, int]] = list(zip(a, b))
print(c)
# [(1, 4), (2, 5), (3, 6)]
