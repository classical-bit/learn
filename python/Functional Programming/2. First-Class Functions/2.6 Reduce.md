# Reduce
The built-in functools.reduce() function takes a function and a list of values, and applies the function to each value in the list, accumulating a single result as it goes.

```python
import functools

def add(sum_so_far: int, x: int) -> int:
  print(f"sum_so_far: {sum_so_far}, x: {x}")
  return sum_so_far + x

numbers: list[int] = [1, 2, 3, 4]
sum: int = functools.reduce(add, numbers)
# sum_so_far: 1, x: 2
# sum_so_far: 3, x: 3
# sum_so_far: 6, x: 4
# 10 doesn't print, it's just the final result
print(sum)
# 10
```

Notice that we're passing the function `add` without ()! It means that `reduce` will take care of execution and pass the parameters for you. Think of passing `add` like handling someone a recipe (the instructions), instead of the finised dish (the result of the execution).
