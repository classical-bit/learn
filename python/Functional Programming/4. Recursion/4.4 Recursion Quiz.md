# Recursion Quiz
Consider the following function (assume `n` is a non-negative integer);

```python
def countdown(n: int) -> None:
    print(n)
    if n == 0:
        return
    else:
        countdown(n - 1)
```

__Q__: Which line contains the base case?
__A__: if n == 0

__Q__: Which line has the recursion call?
__A__: countdown(n - 1)

__Q__: What would happen if we swapped `countdown(n - 1)` with `countdown(n)` for n > 0?
__A__: An infinite recursive loop
