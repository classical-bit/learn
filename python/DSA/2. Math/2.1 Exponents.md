An exponent indicates how many times a number is to be multipled by itself.

For example:

5^3 = `5 * 5 * 5` = `125`

Somtimes exponents are also written using the caret symbol (`^`):

## Exponent Syntax
The `**` operator calculates an exponent in Python. (Why not `^` operator? Blame Fortran.)

```python
square = 2**2
# square = 4

cube = 2**3
# cube = 8
```
