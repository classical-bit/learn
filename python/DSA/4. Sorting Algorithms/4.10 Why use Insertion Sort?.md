# Why Use Insertion Sort?
- __Fast__: for very small data sets (even faster than merge sort and quick sort, which we'll later)
- __Adaptive__: Faster for partially sorted data sets
- __Stable__: Does not change the relative order of elements with equal keys
- __In-Place__: Only requires a constant amount of memory
- __Online__: Can sort a list as it receives it

## Why Is Insertion Sort Fast for Small Lists?
Many production sorting implementations use insertion sort for very small inputs under a certain threshold (very small, like `10`-ish), and switch to something like quicksort for larger inputs. They use insertion sort because:

- There is not recursion overhead
- It has a tiny memory footprint
- It's stable sort as described above

## Reference

```python
def insertion_sort(nums: list[int]) -> list[int]:
  for i in range(len(nums)):
    j = i
    while j > 0 and nums[j - 1] > nums[j]:
      nums[j], nums[j - 1] = nums[j - 1], nums[j]
      j -= 1
  return nums
```
