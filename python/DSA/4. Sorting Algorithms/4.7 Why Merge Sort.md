# Why Merge Sort?

Pros:
- __Fast__: Merge sort is much faster than bubble sort. `O(n*log(n))` instead of `O(n^2)`.
- __Stable__: Merge sort is a stable sort which means that values with duplicate keys in the original list will be in the same order in the sorted list.

Cons:
- __Memory usage__: Most sorting algorithms can be performed using a single copy of the original array. Merge sort requires extra subarrays in memory.
- __Recursive__: Merge sort requires many recursive function calls, and in many languages (like Python), this can incur a performance penalty.
