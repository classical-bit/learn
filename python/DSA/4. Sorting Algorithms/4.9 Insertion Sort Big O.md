# Insertion Sort Big O
Insertion sort code for reference:

```python
def insertion_sort(nums: list[int]) -> list[int]:
    for i in range(len(nums)):
        j = i
        while j > 0 and nums[j - 1] > nums[j]:
            nums[j], nums[j - 1] = nums[j - 1], nums[j]
            j -= 1
    return nums
```

Insertion sort has a Big O of `O(n^2)`, because that os ots worst case complexity.

The outer loop of insertion sort always executes `n` times, while the inner loop depends on the input.

- __Best case__: If the data is pre-sorted, insertion sort becomes really fast. Can you see why? Because the inner loop terminates after a signle comparision, dropping the time complexity from `O(n^2)` down to a linear `O(n)`.
- __Average case__: The average case is `O(n^2)` because the inner loop will execute about half of the time.
- __Worst case__: If the data is in reverse order, it's still `O(n^2)` and the inner loop will execute every time.
