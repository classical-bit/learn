# Pure Functions
If you take nothing else away from this course, _please_ take this: pure functions are fantastic.
They have two properties:
- They _always_ return the same value given the same arguments.
- Running them causes no side effects.

In short: __pure functions don't do anything with anything that exists outside of their scope__.

## Example of a Pure Function

```python
def find_max(nums: list[int]) -> float:
  max_val: float = float("-inf")
  for num in nums:
    if max_val < num:
      max_val = num
  return max_val
```

## Example of an Impure Function

```python
# instead of returning a value
# this function modifies a global variable
global_max: float = float("-inf")

def find_max(nums: list[int]) -> None:
  global global_max
  for num in nums:
    if global_max < num:
      global_max = num
```
