# Input and Output
Ther term "i/o" stands for input/output. In the context of writing programs, i/o refers to anything in our code that interacts with the "outside world." And "outside world" just means anything that's not stored in our application's memory (like variables).

## Examples of I/O
- Reading from or writing to a file on the hard drive
- Accessing the internet
- Reading from or writing to a database
- Even simply printing to the console!!

All i/o is a form of "side effect."
